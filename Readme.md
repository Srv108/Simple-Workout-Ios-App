# 🏋️‍♂️ Simple Workout iOS App

A clean and user-friendly iOS application built with Swift that helps users track workouts and stay motivated. The app includes secure login, a stopwatch, structured daily workout routines with videos, and a profile management page.

---

## ✨ Features

- ✅ **User Authentication**  
  - Register and login with form validation.
  - Redirects to the Home page after successful login.

- 🕒 **Stopwatch Tab**  
  - Functional stopwatch to time exercises and intervals.
  - Easy start, pause, and reset functionality.

- 📆 **Workout Tab**  
  - Displays a list of workout days (e.g., Day 1, Day 2, etc.).
  - Each day includes:
    - A list of exercises
    - Descriptions and instructions
    - Embedded instructional videos

- 👤 **Profile Tab**  
  - View user details.
  - Manage account information (e.g., name, email).
  - Option to log out and reset progress (if implemented).

---

## 📱 App Structure

- **Login/Register Screen**  
  User-friendly forms with input validation.

- **Home Page (Tab Bar Controller)**  
  Contains 3 main tabs:
  1. **Stopwatch** – Control your workout time.
  2. **Workout Plan** – Explore daily exercises and videos.
  3. **Profile** – View and manage your account.

## 🛠️ Tech Stack

- **Language:** Swift
- **UI Framework:** UIKit / SwiftUI (depending on your implementation)
- **Video Player:** AVKit or WebView
- **Architecture:** MVC / MVVM (optional)
- **Navigation:** UITabBarController + UINavigationController
